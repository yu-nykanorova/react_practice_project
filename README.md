# React + TypeScript + Vite

## Homework 8

Create a state that will be responsible for posts and comments (with jsonplaceholder). Make appropriate routes. Create a route "/complex", which will display the following data when you navigate to it: user + his posts + post comments. Switching to this route is possible only if up to this point you have visited a page with users, posts, comments and thus filled the page. Or think over the logic that will take into account the presence or absence of data, and if necessary, fill the page yourself. Accordingly, get the data from the store, and not pull it again from the API.

## Technologies
- React + Vite
- React Router DOM
- Redux Toolkit
- Typescript
- Axios
- TailwindCSS

## Getting started

1) Clone the repository
```bash
git clone <repository-url>
```
2) Go to the project folder
```bash
cd <project-folder>
```
3) Install dependencies
```bash
npm install
```
4) Run project
```bash
npm run dev
```
The project will be available at: http://localhost:5173
