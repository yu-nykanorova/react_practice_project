# React + TypeScript + Vite

## Homework 5, task #UYuu2f1

### Part 1
Get to know the API http://owu.linkpc.net/carsAPI/v1/doc

### Part 2
Create a page that displays all cars (with minimal information)

### Part 3
Create a page with a form for creating car objects.     
Create services for working with the API (service operation via axios).

### Part 4
Implement validation according to the API documentation so that the car cannot be saved if it does not meet the conditions.

Add minimal styling.

## Technologies
- React + Vite
- React Router DOM
- Typescript
- Axios
- TailwindCSS

## Getting started
1) Clone the repository
```bash
git clone <repository-url>
```
2) Go to the project folder
```bash
cd <project-folder>
```
3) Install dependencies
```bash
npm install
```
4) Run project
```bash
npm run dev
```
The project will be available at: http://localhost:5173
