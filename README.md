## Getting started
1) Clone the repository
```bash
git clone <repository-url>
```
2) Go to the project folder
```bash
cd <project-folder>
```
3) Install dependencies
```bash
npm install
```
4) Run project
```bash
npm run dev
```
The project will be available at:
http://localhost:5173
