https://jsonplaceholder.typicode.com/todos – look at the data array.
Create a TodoComponent that will store information about the same object of the array.
Create a TodoComponents component in which iterates on the array of data captured from the API.
App is a root component.

## Technologies
- React
- Typescript
- Vite
- Fetch API
- TailwindCSS

## Getting started
1) Clone the repository
```bash
git clone <repository-url>
```
2) Go to the project folder
```bash
cd <project-folder>
```
3) Install dependencies
```bash
npm install
```
4) Run project
```bash
npm run dev
```
The project will be available at:
http://localhost:5173
